# ビットゲーム — 2進数・16進数で遊ぶ

ビットを指でタップして数字を作る、2進数・16進数の学習ミニゲーム集。中高生でも片手で
気軽に遊べて、遊んでいるうちに桁の重み・16進数・繰り上がりが身につきます。スマホの
ブラウザで動く PWA（インストール不要・オフライン対応）です。

## 収録モード

### 🗼 ビットタワー（おすすめ）
「＋N」をビットで足していく **加算クライム**。編集する4ビットは **16進の一番下の桁**そのもの。
桁が **F（1111）を超えると桁上がり**して上の桁へ繰り上がり、フロアが上がってレベルアップ！
「2進の桁の重み → 16進1桁 → 繰り上がり（F→10）」を丸ごと体で覚えられます。

### ⚡ ビットブリッツ
制限時間内にお題（10進/16進）をビットで変換。コンボを繋いでハイスコアを狙う反射スコアアタック。

### 🧩 ビットドロップ
落ちてくる数字ブロックを、着地前にスイッチを合わせて消す落ちものパズル。積むとゲームオーバー。

## 遊び方（ビットタワー）

1. 上の **16進トータル**が今の高さ。末桁（金色）が編集中の桁です。
2. 「**＋N**」を、今の桁に足した値になるようビットをタップして作ります（＝2進の足し算）。
3. 桁が **F を超えたら桁上がり** → フロアが1つ上がって大興奮の演出。
4. 制限時間はフロアが上がるほど短く。ミスでライフが減り、0でゲームオーバー。
5. **桁の重み**表示を消すと上級モード。ベストスコアは端末に保存されます。

## 起動方法（ローカル）

ビルド不要の静的サイトです。任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages でもそのまま動きます（参照は全て相対パス）。

## テスト

ゲームロジック（`js/logic.js`）のユニットテスト：

```bash
node --test
```

## 構成

```

drop.html  + js/drop.js    ビットドロップ（落ちものパズル）
js/logic.js             純粋ロジック（変換・桁上がり・スコア。テスト対象）

js/fx.js                効果音・振動・画面フラッシュ

manifest.webmanifest / sw.js / js/pwa.js   PWA（オフライン対応）
icons/                  アプリアイコン
test/logic.test.mjs     ロジックのユニットテスト
```
