# ビットコリント — 2進数・16進数で遊ぶ

玉を弾いてビットを立てる **コリントゲーム(縁日のピン盤)風** の学習ゲーム。落ちた先のビットが
立ち、**同じ桁に2回入ると桁上げ(繰り上がり)**。最終的な8ビットの値でスコアを競います。遊びながら
2進数・16進数・繰り上がりが身につきます。スマホのブラウザで動く PWA(インストール不要・
オフライン対応)です。

## 遊び方

1. 盤の下部に **8ビット(00000000)**。左が最上位(128)、右が最下位(1)。
2. **画面を押している間パワーが溜まり、離すと右下の発射台から玉が飛ぶ**(パチンコ式)。
3. 玉はピンに当たって跳ねながら落下し、**入ったスロットのビットが `0→1`**。
4. **既に立っている桁に入ると桁上げ**:その桁が0になり、上の桁へ繰り上がる(連鎖して光る)。
5. **弱い玉は右(下位)へ、強い玉は左(上位)へ**届きやすい。上位ビットほど入りにくく、高得点。
6. **10球**撃ち切った時の8ビット値(0〜255 = 0x00〜0xFF)がスコア。**255 = 11111111** が最高。
   ベストスコアは端末に保存されます。

## 起動方法(ローカル)

ビルド不要の静的サイトです。任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages でもそのまま動きます(参照は全て相対パス)。

## テスト

ゲームロジック(`js/logic.js`)のユニットテスト:

```bash
node --test
```

## 構成

```
index.html          ゲーム画面(Canvas + HUD + パワーメーター + スタート/リザルト)
js/corinth.js       ゲーム本体(自作の軽量2D物理:重力・ピン衝突・壁反射・着弾判定)
js/logic.js         純粋ロジック(2進変換・桁上げ dropBall・16進整形。テスト対象)
js/fx.js            効果音・振動・画面フラッシュ
css/styles.css      スタイル
manifest.webmanifest / sw.js / js/pwa.js   PWA(オフライン対応)
icons/              アプリアイコン
test/logic.test.mjs ロジックのユニットテスト
```
