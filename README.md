# ビットビルダー — 2進数・16進数 学習パズル

ビットを指でタップして、お題の数字を作る学習パズルゲーム。二進数の各桁の重み
（1・2・4・8…）を手を動かしながら覚え、16進数との変換にも慣れられます。スマホの
ブラウザで動く PWA（インストール不要・オフライン対応）です。

## 遊び方

1. 画面上部に **お題の数字**（10進 / 16進）が出ます。
2. 下のビットのセルをタップして `0 ⇔ 1` を反転し、**いまの値** をお題に合わせます。
3. 各セルの下の数字はその桁の重み（`8 4 2 1` など）。重みの合計がお題になれば正解です。
4. 正解を重ねるとレベルが上がり、桁数（4→6→8bit）と表記（10進→16進）が難しくなります。

- **連続正解** と **速答** でスコアにボーナスが付きます。
- **桁の重みを表示** のチェックを外すと、ヒントなしの上級モードになります。
- ベストスコアは端末に保存されます。

## レベル進行

| レベル | ビット幅 | 出題表記 |
|--------|----------|----------|
| 1 | 4bit | 10進 |
| 2 | 4bit | 10進 + 16進 |
| 3 | 6bit | 10進 + 16進 |
| 4 | 8bit | 10進 + 16進 |
| 5 | 8bit | 16進のみ |

各レベルは 5 問正解で次へ進みます。

## 起動方法（ローカル）

ビルド不要の静的サイトです。任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## テスト

ゲームロジック（`js/logic.js`）のユニットテスト：

```bash
node --test
```

## 構成

```

js/logic.js             純粋ロジック（テスト対象）
js/game.js              UI・状態管理・入力処理
js/pwa.js               Service Worker 登録
manifest.webmanifest    PWA マニフェスト
sw.js                   Service Worker（オフライン対応）
icons/                  アプリアイコン
test/logic.test.mjs     ロジックのユニットテスト
```
